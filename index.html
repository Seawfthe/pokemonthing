Config

API settings

HoloDex runs fine without a key — the public Pokémon TCG API allows about 1,000 requests a day. If you search a lot, grab a free key at dev.pokemontcg.io and paste it below. It is stored only in this browser.

Mode: direct API

日本語 → 中文

The 中文 button in a Japanese card's detail view translates its Japanese name, attacks, abilities and flavour text into Chinese. English card details are left untouched. The local server does the work and caches the result on disk.

Cached data

Search results and card prices are cached locally for a few minutes to keep the API happy.

SNKRDUNK JP prices are fetched and matched by the local server, then cached for an hour.
