Admin sign in

Control which cards appear on HoloDex and override any card's price. Credentials are verified by the local server — the password never touches the browser.

Default credentials live in server.mjs (or ADMIN_USER / ADMIN_PASS). Sessions expire after a day; signing out clears the token.

Admin mode needs the local server. Run node server.mjs and open http://localhost:4310/admin.
